# Introduction to Image Processing, Sampling, Quantization and Image Operations
This lab introduces the fundamentals of Digital Image Processing using Python. The experiment focuses on image loading, visualization, color space representation, grayscale conversion, image properties, and histogram analysis. Also This lab explores image sampling, quantization, pixel relationships, distance measures, and arithmetic/logical operations on images. Various image manipulation techniques are implemented and analyzed using Python and OpenCV.

## Topics Covered

- Loading and displaying images
- Understanding image dimensions and data types
- RGB and Grayscale image representation
- Image channel inspection
- Histogram generation and analysis
- Basic image visualization using Matplotlib
- Image sampling and quantization
- Pixel neighborhoods and connectivity
- Distance measures
  - Euclidean Distance
  - City Block Distance
  - Chessboard Distance
- Arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Logical operations
  - AND
  - OR
  - NOT
  - XOR
- Image blending
- Image masking
- Background subtraction


## Tools Used

- Python
- OpenCV
- NumPy
- Matplotlib


## Learning Outcomes

- Understand how digital images are represented in computers
- Analyze image properties and color channels
- Visualize image intensity distributions using histograms
- Gain familiarity with Python-based image processing libraries
- Understand the effects of sampling and quantization on image quality
- Analyze pixel relationships and connectivity
- Perform arithmetic and logical image operations
- Apply image blending and masking techniques
