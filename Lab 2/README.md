## Lab 2 — Intensity Transformations & Bit Plane Slicing

Basic point-processing operations on grayscale and color images.

- Image brightening using pixel-wise addition
- Digital negative of an image
- Contrast adjustment using histogram equalization
- Contrast stretching (min-max normalization)
- Bit plane slicing (extracting and visualizing all 8 bit planes)

**Tools:** OpenCV, NumPy, Matplotlib
