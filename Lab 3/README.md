## Lab 3 — Histogram Processing & Image Properties

Histogram-based contrast enhancement and fundamental image matrix operations.

- Logarithmic transformation
- Power-law (gamma) transformation
- Histogram equalization with before/after histograms
- Histogram matching (specification) against a reference image
- Image matrix representation, pixel value lookup, image dimensions, and full image metadata (shape, dtype, min/max pixel values, total pixel count)

**Tools:** OpenCV, NumPy, Matplotlib, `skimage.exposure.match_histograms`
