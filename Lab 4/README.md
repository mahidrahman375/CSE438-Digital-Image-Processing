## Lab 4 — Spatial Filtering & Noise Removal

Noise simulation and restoration using order-statistic and smoothing filters.

- Salt-and-pepper noise removal using min and max filtering (with PSNR comparison across filter orders)
- Gaussian noise removal using Gaussian filtering
- Comparison of box filtering, weighted average filtering, and median filtering (with PSNR-based evaluation)
- Image sharpening using unsharp masking and high-boost filtering (Laplacian variance used as a sharpness metric)
- Image sharpening using the Laplacian filter
- Edge detection using Roberts Cross, Sobel, and Prewitt operators

**Tools:** OpenCV, NumPy, SciPy (`ndimage`), Matplotlib
