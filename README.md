## Laboratory Experiments

### Lab 01: Introduction to Image Processing

* Image loading and visualization
* Image formats and color channels
* RGB and grayscale conversion
* Histogram visualization
* Image properties and metadata

### Lab 02: Sampling, Quantization and Image Operations

* Sampling and quantization
* Pixel relationships
* Distance measures
* Arithmetic image operations
* Logical image operations
* Image blending and masking

### Lab 03: Gray-Level Transformations

* Thresholding
* Bit-plane slicing
* Contrast stretching
* Intensity level slicing
* Log transformation
* Power-law (Gamma) transformation

### Lab 04: Histogram Processing

* Histogram computation
* Histogram equalization
* Local histogram equalization
* Histogram matching
* Contrast enhancement analysis

### Lab 05: Spatial Filtering (Smoothing)

* Mean filtering
* Weighted-average filtering
* Gaussian filtering
* Median filtering
* Noise reduction analysis

### Lab 06: Spatial Filtering (Sharpening)

* Laplacian sharpening
* Unsharp masking
* High-boost filtering
* Edge enhancement

### Lab 07: Edge Detection

* Sobel operator
* Prewitt operator
* Laplacian of Gaussian (LoG)
* Canny edge detection
* Edge comparison analysis

### Lab 08: Frequency Domain Processing

* 2D Discrete Fourier Transform (DFT)
* Frequency spectrum visualization
* Low-pass filtering
* High-pass filtering
* Butterworth and Gaussian filters

### Lab 09: Compression and Hough Transform

* Discrete Cosine Transform (DCT)
* Wavelet Transform
* Image compression
* Hough Line Detection
* Hough Circle Detection

### Lab 10: Image Restoration

* Noise modeling
* Gaussian noise
* Salt-and-pepper noise
* Speckle noise
* Wiener filtering
* Image quality assessment

### Lab 11: Image Segmentation

* Global thresholding
* Adaptive thresholding
* Otsu's method
* Region growing
* Split-and-merge segmentation
* Color segmentation

### Lab 12: Morphological Operations

* Erosion
* Dilation
* Opening
* Closing
* Morphological gradient
* Connected component analysis
* Object recognition
